# Cyberpunk-Blåhaj-Ads
A simple mod replacing a bunch of textures to add Blåhaj themed ads and film posters.

## Installation
1. Head over to the [latest release](https://github.com/Lich-Corals/cyberpunk-blahaj-ads/releases/) and download the `blahaj_ads.zip` file.
2. Extract the file
3. Copy the contents of the file (a single folder called `archive`) into your game's root folder and merge the existing folders.   
5. Done! Now you can start the game as you normally would.

## Modding the mod
You are welcome to modify the mod to your own wishes.
You may also submit a pull request if you want to share your changes with others!

The mod was created with the help of [Wolvenkit](https://wiki.redmodding.org/wolvenkit) and the repository contains everything needed to set up a copy of the project in Wolvenkit.

More information on [Github](https://github.com/Lich-Corals/cyberpunk-blahaj-ads).
