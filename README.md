## Installation
1. Head over to the [latest release](https://github.com/Lich-Corals/cyberpunk-blahaj-ads/releases/) and download the `blahaj_ads.zip` file.
2. Extract the file
3. Copy the contents of the file (a single folder called `archive`) into your game's root folder and merge the existing folders.   
> [!TIP]
> The root folder is normally located at...
> - `C:\Program Files (x86)\Steam\steamapps\common\Cyberpunk 2077` for Steam users
> - `C:\Program Files (x86)\GOG Galaxy\Games\Cyberpunk 2077` for GOG users
> - `C:\Program Files\Epic Games\Cyberpunk 2077` for Epic Games users
> - or `~/.steam/steam/steamapps/common/Cyberpunk 2077/` for Steam users on GNU/Linux
5. Done! Now you can start the game as you normally would.
